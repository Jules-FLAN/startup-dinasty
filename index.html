How a review works

Rules find the problems. Claude writes the explanation. A person makes the call.

  1. 01

    Import

    Add one or more PDF invoices.

  2. 02

    Extract

    Supplier, number, date and amount are read and normalized.

  3. 03

    Check

    Fixed rules compare invoices and record the evidence.

  4. 04

    Review

    Each alert comes with an explanation and a suggested check.

Alerts are reproducible

The same invoices always give the same alerts. The AI explains them but does not create them.

No action without a person

Dinasty does not pay, send reminders or change accounting data.

Only what is needed is sent

The AI receives extracted fields, not the full document, and only after you agree.

Nothing is stored

Files are processed in memory and discarded when the session ends.
