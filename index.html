The problem

Small invoice mistakes. Unnecessary follow-up.

Teams reviewing supplier invoices need to compare references, amounts and dates. Dinasty is being built to make potential issues easier to spot and understand.

01

Possible duplicates

Numbers written differently can still refer to the same invoice. Flag similar supplier records for a second look.

02

Missing information

Missing invoice dates or references should not pass unnoticed. Surface unknown fields without making up values.

03

Hard-to-explain flags

An alert is only useful when a person knows what triggered it and what evidence to check next.

Local prototype workflow

Designed to support a reviewer, not replace one.

We combine fixed checks with optional Claude-generated explanations. A human decides what to do with each flagged document.

Frequently asked questions

Questions before you get in touch?

What is Dinasty Invoice?

Dinasty Invoice is an early-stage, AI-assisted supplier invoice review project. Its local prototype checks text-based invoices for potential duplicates, missing information and basic inconsistencies.

Can my company use it today?

The source code for the local Streamlit prototype is public on GitHub. There is not yet a hosted business product, customer account system or paid subscription.

Does Dinasty replace an accounting system?

No. The prototype is an early review assistant. It cannot post entries, pay invoices, contact suppliers or replace accounting controls.

Does the website analyze my files?

No. The interactive examples on this page are fictitious and run entirely in your browser. The separate Python application can process text-based PDFs locally. Its optional Claude mode sends extracted fields and alerts to the API only with a user's explicit opt-in.
