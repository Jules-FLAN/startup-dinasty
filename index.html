How it works

From PDF to a reviewed report

  1. Import

    Drop in one or more PDF invoices.

  2. Extract

    Key fields are read and normalized. Unclear fields stay "Unknown".

  3. Check

    Deterministic rules flag duplicates and gaps, with the evidence.

  4. Review

    Claude explains each alert. A person decides what happens next.

Rules find, AI explainsAlerts come from reproducible rules. Claude does not create them.
Human approval, alwaysDinasty never pays, sends reminders or edits accounting data.
Minimal dataOnly extracted fields are sent to the AI, after explicit consent.
No retention by defaultDocuments are processed in memory and not stored.
